# Design System (humano)

Este design system foi escrito manualmente, com observações práticas para guiar a implementação de uma interface iOS-like. Não há geração automática por IA. É um conjunto de decisões de design pensadas para comunicar clima de forma clara e humana.

Princípios
- Clareza acima de ornamento: priorize dados e contexto.
- Tipografia como hierarquia: escolha tamanhos e pesos com parcimônia.
- Ritmo visual: espaçamentos consistentes, blocos de informação.
- Acessibilidade: contraste adequado, linguagem amigável, no jargão técnico.

Arquivos
- `tokens.json`: cores, tipografia, espaçamentos, raios, sombras.
- `guidelines.md`: regras de uso (cards, listas, botões, badges), tom de voz.
- `palette.png`: paleta exemplificativa (imagem simples).
