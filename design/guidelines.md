# Diretrizes de UI

Tipografia
- H1: 24–28px, semibold, letra −0.01em
- Auxiliar: 15px, cor muted
- Corpo: 17px, regular

Espaçamento
- Ritmo: 8, 12, 16, 24
- Card interno: ~16–20px
- Entre blocos: ~16–24px

Cards
- Fundo branco, raio 16–20px, borda sutil
- Agrupar informações com títulos curtos

Listas
- Divisor 1px (#e5e7eb) é suficiente
- Foque em dados, poucos ícones

Botões
- Primário: azul iOS (#0a84ff), texto branco, raio ~12px
- Secundário: branco com borda #e5e7eb
- Altura: 40–44px

Badges
- Verde (#34c759) para OK; vermelho (#ff3b30) para erro
- Texto curto (OK, ERRO)

Tom de voz
- Direto, humano, sem jargão
- Diga o que aconteceu e o que fazer

Acessibilidade
- Contraste AA
- Alvos de toque confortáveis
