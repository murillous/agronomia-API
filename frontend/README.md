# Mockups (Figma-style)

Estas telas são mockups estáticos no estilo Figma, feitos manualmente em HTML/CSS/SVG. Buscam um visual iOS-like (limpo, tipografia elegante, hierarquia clara). Use-os como referência de design para um futuro app web/mobile.

Conteúdo:
- `index.html`: Navegação entre telas.
- `styles.css`: Tipografia iOS-like, grelha, tokens básicos.
- `home.html`: Painel com métricas de clima.
- `details.html`: Lista e detalhe de registros.
- `components.svg`: Biblioteca de componentes base.

Fontes:
- iOS usa San Francisco. Para web, utilizamos a stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`.

Como visualizar:
Abra os arquivos `.html` diretamente no navegador ou use um servidor estático.
